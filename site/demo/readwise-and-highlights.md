Two folders hold highlights that tools write into the notebook. Notes link to them, but they're never edited by hand, since the next sync could overwrite the change.

## Readwise highlights

`readwise/` has one file per book or article, synced daily from Readwise. [The Readwise Highlights page](/readwise/) groups them by category, and each page lists its highlights as quotes. See [Walden](readwise/walden.md) and [The Way to Wealth](readwise/the-way-to-wealth.md).

## Other highlights

`highlights/` has passages saved by a separate reading app, from articles, PDFs, and newsletters, each with a summary of the source. [The Other Highlights page](/highlights/) lists them newest first. See [Self-Reliance](highlights/self-reliance.md).

## Searching them

They're left out of search unless asked for, since there are usually far more highlights than notes. See [How Search Works](how-search-works.md).
